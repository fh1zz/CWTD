# 工作室模板在本项目中的使用

已阅读 `F:/Claude/_code/_game/_studio` 的入口、组织及相关工作流；其提供49个agent角色、73个skill、12个hook和11条规则。没有修改原工作室目录，也没有把全部Claude专用hook当作Codex已运行的功能。

本次采用team-combat的分工：策划子代理负责六系统GDD、来源矩阵与验收判据；核心程序子代理负责不依赖Unity的规则模拟和回归；技术审查子代理只读复核Unity接入和界面交互；主代理负责原始截图理解、方案裁决、表现层、原创美术、集成和构建。

采用数值设计skill明确护甲、DPS、成长与三合一的容量取舍；采用游戏UI skill区分战斗信息、暂态提示和模态输入；imagegen生成原创资源。所有模板约束都服从用户真实请求，模板中的角色名或派工数值不是用户的原始策划。

Claude Code模板不会自动变成Unity编辑器里的功能。本项目交付的是独立Unity源码、配置、美术、设计和可复跑验证入口；之后可在此基础上接入工作室的自动化流程。
