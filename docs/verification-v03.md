# v0.3交付与验证：自动主动技

日期：2026-09-06。用户要求宠物主动技能自动释放，本轮为现有七宠设计并实现35阶自动技能；构建及规则验证通过。可见画面与真实点击验收仍未完成。

## 实际交付

- 普攻＋被动沿用v0.2，新增七种自动主动技、每种五阶参数；一阶即可使用，首次3秒战斗时间、之后按9～15秒CD。
- 金隼真实齐射；木毒爆与易伤；獭范围强慢；狐焰爆和独立灼烧；龟震击定身；鹿临时增伤攻速；蝠低血猎袭与非精英处决。
- 没有宠物手动施法接口或按钮。无目标保留就绪，准备／池内／暂停／终局冻结；回收重部署与合成不刷新主动CD。
- 五阶段图鉴分普攻被动／自动技显示，选中宠物有只读冷却与当前有效战斗数值，敌人有缚／灼／弱文字提示。星雨明确为手动全局指令。
- 8张本轮参考截图原样归档；具体数值与设计差异在[技能设计](../design/gdd/v03-automatic-pet-skills.md)。没有将凤凰、龙、狐法、恶犬和火山龟直接加入七宠编队，也没有虚构能量、复活或改路实现。

## 核心测试口径

35阶段矩阵直接运行GameModel.Tick，不调用任何手动宠物施法方法。冷却、范围与伤害必须取实际active配置。现有v0.2普攻效果单元场景在深拷贝测试配置中关闭active，隔离基础被动数值；新的自动技能矩阵和九次完整策略模拟启用真实35条配置。CoreChecks前后校验传入配置未被测试修改。

专项覆盖：无目标不耗CD、不累积多发；光鹿没有合适伙伴不释放；初次和循环计时；暂停／准备冻结；回收清临时增益且保留CD；进化保留CD与新技能；多目标一次命中；毒＋烧独立与易伤只乘一次；部分tick持续效果不四舍五入；精英控制半申请时长／处决免疫；主动不递归普通溅射、不重置普攻；1/60、0.1及10秒长dt的确定性分片。

## 复跑

Unity菜单Forestkeepers → Verify and Build Windows；批处理入口PetTD.EditorBuild.BuildGame.Build。核心与专项一起运行，异常中断构建。

Windows支持-tdCapture <绝对PNG路径> -tdPage verify诊断，输出同目录ui-state-check-results.md并退出，不保存资料。程序在Builds/Windows/Forestkeepers.exe，必须保留同目录依赖。正常可见窗口的操作验收仍需单独进行。
