# v0.3.2：攻击弹线修正

日期：2026-09-06。用户要求“攻击弹线有问题，查看并修复”。本轮针对当前工程的绘线实现做了检查和确定性复现；未收到进一步定位截图，不将推断描述成用户已确认的具体画面。

## 已确认的问题与修正

1. **旋转与窗口缩放顺序错误。** 原Line把参考坐标的a点直接传入GUIUtility.RotateAroundPivot，此时GUI.matrix已包含窗口缩放与留白平移。旋转左乘已有矩阵，参考空间的轴心与屏幕空间混用；默认1600×900也受影响。固定用例a=(900,600)、b=(600,200)下旧起点偏移322.49像素。现在从局部原点绘线，使用parent × TRS(a, rotation, 1)，起点、终点和宽度一起正确投影；try/finally恢复原矩阵和颜色。道路、方向箭头共用该函数，也同步修正。实现依据：[Unity 2022.3 GUIUtility源码](https://raw.githubusercontent.com/Unity-Technologies/UnityCsReference/2022.3/Modules/IMGUI/GUIUtility.cs)的RotateAroundPivot矩阵组合，结合本地调用位置复现；不是Unity所有绘线场景都失效。
2. **连接脚底而非身体。** 出手事件新增SourceLevel、TargetId、TargetKind，只用于表现。发射点从实际35阶段图集拟合矩形内计算，受击点按四种怪物精灵尺寸放在身体内；后来进化不会改变已经发出的事件所用阶段。宠物图集本身没有修改。
3. **目标移动后弹线仍指向旧位置。** 指向单体的反馈在每个模拟步后按稳定敌人ID更新终点；敌人列表重排不影响目标。目标死亡／移除后保留最后位置，不回跳到最初位置，也不转向另一只敌人。范围技能仍固定在真实施法落点，不随某只怪物移动。
4. **伤害与飞行表现不一致。** 现有玩法是出手即结算伤害，本次不更改伤害、DPS或寻敌顺序。普通攻击使用即时短促闪线和命中火花，0.16秒内渐隐；指向型自动技能闪线约0.16秒内收束，后续只留命中反馈。范围自动技能显示范围脉冲，星雨显示真实半径和落点，不再拿起终点相同的数据画“飞行弹线”。
5. **防御性处理。** 零长度、零线宽、非有限坐标不生成线段，过期／无效时长不显示特效；暂停继续冻结反馈，不引入独立于游戏暂停的战斗特效时钟。

本次采用game-ui-design的缩放、战斗可读性与反馈一致性检查。没有引入物理弹体、弹道碰撞或“到达后才伤害”的新规则；没有改变宠物数值、敌人速度、路线控制点、波次、金币或存档。
