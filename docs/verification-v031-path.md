# v0.3.1：怪物路线修正

日期：2026-09-06。用户反馈“地图上怪物路径有问题，需要优化”。没有收到具体故障位置截图，本轮针对代码中确认的折角、比例和显示偏移修正，不把推断视为用户已确认的复现。

## 已修改

- 道路和怪物共用 TrailGeometry 采样后的中心线。原8个折线控制点保留，6个直角各用12段二次曲线圆滑连接，合计80个路径点；不另画一条与寻路不同的美术道路。
- 移动仍以世界弧长推进，不使用贝塞尔参数当速度。统一世界横纵比1.6:1；显示战场由1450×715调整为1144×715，居中放入原可用区域，起点从屏幕参考X45移至X198、终点从X1495移至X1342。保留原有数值单位，普通攻击、自动技能与星雨范围均使用同一比例常量。
- 修正原横向视觉速度比纵向快约26.75%的问题；新增六种窗口尺寸的等比例投影检查，覆盖720p、900p、1080p、1440p、超宽屏和4K的数学缩放。
- 敌人精灵矩形底边锚定道路位置，不再额外向下偏17参考像素；阴影偏移从13减为2。静态素材自带的透明留白仍然存在，这不是完整逐帧行走动画。
- 准备阶段显示行进方向箭头；入口有箭头和“敌人入口”文字。入口、基地避开HUD侧栏；道路分层整段绘制，避免圆弯采样节点反复半透明叠色。
- 第9个部署点（代码索引8）Y从0.44移至0.47，保留14个地块和索引。所有地块中心到道路至少85.8参考像素，道路边缘与部署阴影留有间隔；七种一阶宠物在每个地块都能覆盖道路。
- 三关同步使用新路线。未增加关卡、独立背景或动态改路；未修改宠物数值、自动技能、敌人速度配置、出怪数量、经济或存档格式。

## 目标与数值口径

目标是“怪物沿看得见的路匀速转弯，玩家在开波前看清入口和终点，部署点既不占路也能攻击”。自动判据：路径不自交、无零长段、相邻采样方向变化小于10度、怪物脚底与显示坐标一致、到达终点仅扣一次生命、暂停／定身保持原路径进度。

距离单位为世界高度1；d=√((1.6Δx)²+Δy²)。基准怪速度0.085世界单位/秒，再乘关卡和类型系数。路径长度用每段实际长度相加，位置按累计弧长线性采样。没有路径距离取整，仅浮点误差容差。

本次路线长度2.9600→2.7786，缩短约6.13%；基础速度无增减速的全程时间34.82→32.69秒。第一关普通怪乘0.85速度系数后为约38.46秒。圆角减少在路上的时间，可能改变受击窗口，不等同于“完全不影响难度”。

按 game-balance-design 的模板计算一阶金隼在索引8地块对第一关普通怪的普攻上限参考：DPS仍22.609，理论射程覆盖时长17.632→17.004秒，满覆盖普攻伤害398.636→384.444。输入保留在 path-balance-before.json / path-balance-after.json，由该技能的 balance_metrics.py 计算；忽略技能、目标竞争和离散第一发时点，不作为实际击杀伤害承诺。

## 未完成及下一步

隐藏窗口捕获仍为纯黑，不能证明实际可见画面正常，也不能宣称视觉／物理鼠标端到端测试通过。黑图仅留作诊断，不用作效果展示。本次路径的可读性与比例检查参考 game-ui-design 的缩放、HUD避让和信息提示规范；实际可见窗口还需确认怪物是否贴路、圆角是否自然以及大型精英遮挡。

真人验证建议：三个关卡各观察一整波；分别在直线和拐角暂停／恢复，确认精灵脚底、血条、入口与基地；选中一只宠物对照射程。分别在1600×900和一种超宽比例检查UI不挡路。记录漏怪位置、通关生命、在场数量、帧时间和主观走位问题。

目前普通策略仍全满血，强弱差异未做真人调优。下一轮如果难度偏易，单独调整出怪间隔或HP中的一项，再跑相同种子；不要在路径修正时同时修改多组战斗数值。动态阻路、单位间避让、多车道和完整动画不在本次修复范围内。
