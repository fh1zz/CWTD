# 战斗、宠物定位与数值

> v0.2变更：真实用户现要求“扭蛋直接孵出宠物，每宠共5阶段”。本篇保留v0.1原案追溯；当前即抽即用、35阶段数值／技能／图鉴和新增验收以 [v0.2设计](v02-direct-pets-five-stages.md) 为准，旧等待回合规则不再生效。

版本1.0｜Status: Draft｜来源：EXT-U、EXT-A和已读取的实际balance.json。除“宠物能进化”的概念外，本篇战斗公式、效果与数值均为EXT补全，不代表已阅读OB0.2正文。

## 1. Overview／概述

宠物部署后自动攻击射程内最靠近出口的敌人。七元素各一物种，以穿甲、持续毒、减速、溅射、近程重击、光环支援和快速攻击形成可解释的分工；玩家通过部署、合成和全局星雨改变战局。首版不加入元素相克、暴击、能量或宠物受击规则。

## 2. Player Fantasy／玩家体验

玩家能从短射程重击、范围爆炸和泡泡减速的反馈理解宠物用途。升级增加战力但合并会减少覆盖点，保持铺场与升阶的选择。星雨提供可控补救，CD、落点与结果清晰，不用尚未定义的能量条解释不能施放。

## 3. Detailed Rules／详细规则

### B02：寻敌、攻击与伤害时点

仅Running且未Paused时推进战斗。每只塔当Cooldown≤0时，在Distance(塔,敌人)≤Range(塔)的存活敌人中选最大Progress，平手选最小Enemy.Id；没有目标时CD保持0，取得目标后可立即攻击。攻击后Cooldown增加interval，按实际模拟时间消耗，低帧率不得把每秒攻速变成每帧一次。进化、回收、部署的CD沿用孵化GDD合同。

`EXT-A`：攻击伤害在选定目标并提交攻击时立即结算，CombatFx是短暂弹道表现，不承担二次命中。不会因弹道画完再扣一次血。受伤死亡即移除并奖励一次，后续攻击重新寻敌；宠物出售或成为合成材料不撤销已提交伤害。效果的Life/Duration随模拟推进，暂停冻结；清波时清理剩余表现，不让Preparing等待CD或残留弹道触发伤害。

宠物不承受敌人伤害，没有碰撞阻挡、仇恨切换、经验升级和弹药。Range(Pet)返回该物种配置range，等级不增加射程或攻速。Damage(Pet)返回等级缩放后的基础单次伤害，未包含光环和目标护甲，避免UI和实际攻击重复加成。

### B03：效果与叠加

| 效果 | 可执行规则 |
|---|---|
| 穿甲armor | 当前目标有效护甲=Armor×(1-effectPower)，之后走普通减伤；不额外加一段伤害 |
| 毒poison | 命中造成基础直伤，再令目标PoisonRemaining=3秒；PoisonDps采用effectPower×等级倍率×施毒瞬间光环倍率；同源按木物种视为一个毒，不按多塔叠加 |
| 减速slow | 命中后SlowRemaining=2秒；现有首版水物种减速比例恒为0.3，重复命中刷新2秒，不相加成60%或永久定身 |
| 溅射splash | 以主目标命中位置为圆心，对半径effectPower内所有当时存活敌人各结算一次本次伤害，含主目标，不给主目标重复伤害；每目标单独减甲 |
| 重击heavy | 高damage、短range；不推断击退、眩晕或破甲 |
| 光环aura | 位于光鹿range内的其他已部署宠物获得effectPower增伤，取最强一份，不相加；不自增伤，可被另一只光鹿支持；光环只改攻击输出，不扩大range |
| 疾射rapid | 只由较短interval体现；无暴击、斩杀线或额外溅射 |

毒在敌人存活期间按实际剩余有效时长连续扣浮点HP，不把每帧伤害取整。再次施毒时若原毒仍有效，PoisonDps取原值与新值较大者，持续时间刷新3秒；若已结束则直接采用新值。此为首版“同源刷新”的明确解释：多个木宠不能累加DPS，弱毒刷新会延续当前较高DPS。公开字段不限定私有组织方式；已与core同步并只读核对：原PoisonSource列表已移除，当前用单份PoisonRemaining/PoisonDps取强刷新，毒不累加，到期／死亡／漏怪均清零。

减速取最强是效果语义；首版配置仅水宠30%，当前核心用私有EnemyStatus.Slow存强度、公开SlowRemaining存剩余时间，命中取强且刷新2秒，比例上限95%。公开字段不表示没有私有状态。未来独立多来源到期规则另行扩展。毒无视护甲，直伤照常减甲；敌人出场、死亡、漏怪或重试均清理持续效果。

光鹿位置、移除或等级变动后，在下一次攻击前读取当前范围内有效光环；不永久写入目标damage字段，不把上一帧加成再乘一次。进化光鹿仍为20%而非每级加20%；等级增加它自身攻击，不额外强化effectPower，毒DPS例外按等级伤害倍率成长。星雨不受光环。

### B04：全局星雨

采用实际配置：skillCooldown=35秒，skillDamage=110，skillRadius=0.26。初始补全建议中的100与当前JSON110存在差异；本轮EXT方案采用110。100、110及星雨技能本身都不是18张截图明确提供的设计。以后运行以实际JSON为准。

进入新局SkillRemaining=0，技能可用。仅Running允许选择并提交落点；点击技能进入瞄准，画面预览有效圆形范围，点击战场有效坐标施放，对圆内存活敌人各造成110点无视护甲伤害，立即结算一次并设35秒CD。可打空，合法空地落点仍消耗CD；越出战场、UI覆盖区域、冷却中、Preparing、Paused、Won或Lost均拒绝且不消耗。右键／Esc取消瞄准不耗CD。

技能伤害不随波数、宠物等级、光鹿或队伍长度增加，无能量、次数货币、购买重置或付费恢复。准备期不回CD；进入下一波继续剩余CD；重试重置为0。有效CD显示ceil(SkillRemaining)秒，但可用性按原始剩余值≤0判断，不能等到显示0之后再延迟1秒。

### B05：经济与成长的取舍

等级1..5提升倍率为levelDamageScale^(Level-1)，实际levelDamageScale=2.05。三只同级合成一只，合成后单位置威力为原单只2.05倍，总直伤能力约为原三只的68.33%，换取池／地块容量；不能假称合成必然提高总DPS。覆盖有限地块、毒不叠加与光环范围使多种策略各有情形。

初始3只赠宠与金币保障首波可操作，但不保证任意站位、任意一物种队伍必胜。原型三关目标以1～2级为主、少量3级，4～5级是规则上限和构造数据验收范围。仅算购买成本，5级需要81只同种1级=4050金币，已高于第三关全击杀、不出售总收入3556；因此不把“自然打三关升5级”写成体验承诺。若未来要常态体验高阶段，应通过长局模式或独立经济调参扩展。

## 4. Formulas／公式、单位与算例

D为单次原始damage，L为整数1..5，q=2.05，I为interval秒，A为非负护甲点数，p为穿甲比例0..1，b为本次最强有效光环比例（当前0或0.2）。所有数学输入必须有限，不接受NaN／Infinity。

- F(L)=q^(L-1)；五级倍率依次1、2.05、4.2025、8.615125、17.66100625。
- Damage(Pet)=D×F(L)；普通直伤=D×F(L)×(1+b)×100/(100+A)。金隼以A×(1-p)替换A。
- 护甲不是百分数：A=100时普通伤害减半；金隼p=0.5时减伤系数100/150=2/3。A=0时无减伤，不出现分母0；负护甲输入视为无效配置／测试输入，运行防御性按0处理。
- 基础DPS=D×F(L)/I；实际DPS需乘命中利用率、护甲与光环，火狐再按实际被命中的目标数分别求和，不假设永远击中3只。
- 毒伤=PoisonDps×min(dt,PoisonRemaining)，累计到剩余时长归0；毒用施加时倍率快照，不受后续光鹿离场倒扣。
- 减速位移=Speed×[(1-s)×min(dt,SlowRemaining)+max(0,dt-SlowRemaining)]，s=0.3；例dt=1秒、剩余减速0.25秒，则相当于正常行进0.925秒，不能整秒都减速。
- Elapsed只累计有效Running秒数；Cooldown和SkillRemaining下界0；暂停dt_effective=0。毒、减速跨子步到期按有效片段计算。
- 金币只在出售、击杀、清波和抽取事务中作整数加减；战斗HP和伤害不取整，只在显示时按需要保留1位小数或向上取整HP。禁止使用显示数字反写状态。

| 算例 | 结果 |
|---|---|
| 1级金羽隼打A=100，穿甲50%，无光环 | 26×100/150=17.3333…伤害 |
| 同一击有20%光环 | 20.8伤害 |
| 2级烬尾狐打A=0的3只敌人 | 每只28×2.05=57.4，总172.2；没有主目标双算 |
| 1级芽灵毒，无光环，完整3秒 | 6×3=18点毒伤，另外计已发生的13点直伤 |
| 2级芽灵有光环的毒 | 6×2.05×1.2=14.76DPS，完整3秒44.28 |
| 星雨落点内3只A=100且HP200的敌人 | 各剩90HP，CD35；A不参与技能减伤 |
| 3只1级金隼对比1只2级 | 67.826…DPS对46.348…DPS；忽略覆盖与过量伤害的理论值 |

## 5. Edge Cases／边界情况

射程边界包含等号，半径内同一敌人只处理一次。死亡敌人不会成为溅射中心后的第二次单体命中，也不会贡献两次奖励。目标刚好走到出口且同一模拟时点被击杀，按核心循环统一先伤害后漏怪处理；玩家不能通过表现层弹道速度改变结果。

技能准备瞄准时清波→退出瞄准不扣CD；暂停→取消未提交瞄准并冻结已经提交的技能效果。图层UI挡住的坐标不是合法战场目标。SkillRemaining=0允许施放，>0即使小于显示精度也拒绝。

伤害0只允许无伤害测试，不意外加最小1；interval≤0拒绝配置，避免无限攻击循环。等效护甲极大时伤害接近0但有限；生命≤0立即移除。毒刷新不叠加且不能用反复命中触发额外“首跳”。Preparing暂停战斗时不会靠挂在池中的宠物刷新CD套利。

## 7. Tuning Knobs／参数与验证方案

PetSpec与GameConfig提供配置数值；敌人变体等集中EXT常量另以核心循环GDD为准，候选试验每轮只改一组：damage 5..80、range 0.18..0.45、interval 0.3..2.5秒、levelDamageScale 1.8..2.3、skillRadius 0.12..0.30、光环0.1..0.3、减速0.15..0.5。当前实际值按B01／B04，首版技能CD35固定；effectPower需按effect验证单位，不能把火狐0.11误当11%伤害。

毒3秒、减速2秒为配置description和本规则共同确定的固定时长；现有JSON没有独立duration字段，不宣称可从不存在的字段热改。若要调持续时长，后续统一扩展合同与文案来源。

基准试玩至少包括：教程前三赠宠低投入、均衡5物种铺场、集中合成、双光鹿与多木宠、只带1种、末波才花钱。收集通过率、剩余HP、波时长、金币／未孵蛋剩余量、宠物部署分布、合成次数和失败波次，均仅本地观察，不接入联网遥测。

目标候选：首次完整理解教学的5名体验者中≥4人独立完成部署与开波、≥4人准确解释“第2波孵化”；正常队伍首关首轮胜率目标60%～85%，属试玩目标非已测结论。若过易先只上调baseHp；若新手首波无从开始先修教学，不改概率；若火狐优势仅出现在密集波，先核查群攻重复伤害再调spawnInterval。

## 8. Acceptance Criteria／验收标准

执行AC-B01～AC-B14；全部数值算例底层浮点误差≤0.001，暂停前后数值必须无推进。检验寻敌平手、护甲／穿甲、光环不叠加、毒刷新与过期片段、减速过期片段、溅射主目标一次、技能初始可用／空放／取消／CD跨波。人工表格与计算只构成设计验算，尚不等于实机通过。
