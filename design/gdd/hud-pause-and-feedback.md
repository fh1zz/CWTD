# HUD、暂停、操作与视听反馈

> v0.2变更：真实用户现要求“扭蛋直接孵出宠物，每宠共5阶段”。本篇保留v0.1原案追溯；当前即抽即用、35阶段数值／技能／图鉴和新增验收以 [v0.2设计](v02-direct-pets-five-stages.md) 为准，旧等待回合规则不再生效。

版本1.0｜Status: Draft｜来源：SRC-I01～I05、I07、I10～I18；EXT-A。未在来源中明确规定的呈现细节均为EXT-D。

## 1. Overview／概述

HUD以生命、金币和波号为常驻信息；右侧扭蛋机和下方孵化池提供主要经济操作；选择宠物时才显示关联信息与操作按钮。暂停保留静止地图并隐藏局内UI，以灰色半透明遮罩和菜单覆盖，恢复后回到同一战局状态。

## 2. Player Fantasy／玩家体验

玩家能一眼分清金币不足、池满、等待孵化、可进化与技能冷却。手绘奇幻画面保持道路和角色轮廓清晰，参考用户指定的《王国保卫战》气质；采用原创宠物、场景和图标占位方向。本篇定义表现规格；主代理已另外生成原创位图并接入Unity原型，实际表现验收见docs/verification.md。

## 3. Detailed Rules／详细规则

### U01：布局与阶段信息

按合同使用Unity IMGUI首版表现方案、1920×1080参考坐标；这是主agent提供的EXT原型路线，不用其他UI框架覆盖。战场单独保持约1.6宽高比，与HUD、池和扭蛋的屏幕坐标解耦。整体窗口采用等比缩放／留边，不能挤压逻辑距离。

| 区域 | 显示／操作 | 来源 |
|---|---|---|
| 左上 | 基地HP与金币，图标和数字同时出现 | SRC-I01 |
| 上方中部 | Wave/总波数；Preparing额外显示“准备中／下一波N” | SRC-I01 + EXT-A |
| 右上 | 暂停按钮 | SRC-I01 |
| 右侧 | 扭蛋机、50金币费用、有效队伍概率、收起箭头 | SRC-I04～I05 + EXT |
| 下方 | 10格孵化池、折叠箭头、蛋ReadyWave标签、池批量进化 | SRC-I03、I06～I07、I10 + EXT |
| 下方独立技能区 | 星雨、CD、瞄准态 | EXT-U／实际配置 |
| 可见的波次操作区 | Preparing显示“开始第N波”；Running显示剩余敌人数 | EXT-A／EXT-D |

初始显示0/总波数，而非伪造已开始第1波。末波时扭蛋区常驻“本局无下一回合，无法孵化”。金币和数值始终读取模型；灰态原因来自真实前置条件，不通过界面猜测扣钱。

### U02：选择面板，严格保留截图相对位置

| 选择对象 | 信息位置 | 出售位置 | 进化位置 | 补全与退出 |
|---|---|---|---|---|
| 战场宠物 | 宠物右侧 | 宠物下方 | 满足条件才在宠物上方显示 | 选中边框与射程；另加“回收至池”辅助按钮，不能替换出售 |
| 池内已孵宠物 | 池上方 | 池右下方 | 池右上方，满足池批量条件才出现 | 选中格边框；操作对象使用Uid，不绑定旧格子号 |
| 池内蛋 | 不显示宠物信息 | 不显示 | 不出现蛋的单体进化 | 格子保留ReadyWave状态标签；池全局批量进化可因其他宠物满足条件而存在 |
| 无选择 | 隐藏选中信息 | 隐藏单体出售 | 隐藏单体进化 | 池全局批量进化根据整个池状态独立判断 |

宠物信息显示名称、元素图标、等级、攻击值、攻击间隔（秒）／攻速、射程和效果说明。标明攻击值为基础值，若有光环另行显示“+20%支援”，避免将Damage基础查询与实际结算混淆。`SRC-I02～I03` 点空白取消选择，相关信息和单体按钮消失；`SRC-I11` 进化成功后也清选择。可进化标识属于塔状态，可以在取消选择后继续显示。

右侧信息接近战场边界时，用预留右侧信息栏或界内右侧浮层承载并以指示线关联主体，不能直接裁切或把“右侧信息”随意变成左侧。操作按钮和浮层不遮住点击目标，UI消费点击后不得继续传给地块。

### U03：按钮、灰态与tips

所有按钮具有默认、hover、按下及必要禁用态，按下有轻微缩放／变亮反馈。抽蛋灰态仍能点击解释；进化“条件不满足隐藏”遵从原图，不改成永远显示的灰按钮。池、扭蛋收起展开各用约0.18秒过渡，逻辑折叠目标立刻记录，动画不改变模拟。

全局同一时刻最多1条tips，首次显示持续2秒。其显示期间再次触发任何tips都不新增、不堆叠、不刷新计时；满2秒后再点击可出现新提示。模型LastMessage允许更新，UI以新的失败命令事件触发显示，不能每帧读取旧LastMessage而无限重播。金币不足优先于池满，暂停或终局错误优先于经济原因。

tips按界面可见真实时间计2秒，不受战斗帧率或未来倍率影响；暂停时隐藏原tips并冻结其剩余显示时间，恢复后显示余量。常驻末波说明不属于tips，也不占用tips单例。

建议中文文案：金币不足（需要50金币）；孵化池已满，无法获得宠物蛋；蛋将在第N波开始时孵化；本局无下一回合，无法孵化；宠物蛋不能出售；孵化池已满，无法回收；该地块已有宠物；需要3只同物种同等级宠物；已达最高阶段；当前不是可施放技能阶段。

### U04：暂停全冻结

点击暂停或正常战斗界面Esc：立即Paused=true，地图继续可见，隐藏HUD、池、扭蛋、宠物信息、范围、tips和技能瞄准；加灰色半透明遮罩，显示“回到选关界面／重新开始／继续”和右上关闭按钮。暂停可从Preparing或Running进入；记录之前Stage，不改变Wave、队伍或金币。

| 冻结内容 | 必须保持的值或行为 |
|---|---|
| 敌人 | 位置、Progress、HP、生成数量与出怪计时 |
| 宠物 | 攻击、Cooldown、池内候补Cooldown、进化与部署事务 |
| 技能 | 释放、SkillRemaining、已生成的局内效果 |
| 持续状态 | PoisonRemaining/PoisonDps作用、SlowRemaining及其他战斗BUFF／DEBUFF |
| 回合与经济 | Wave、孵化、清波判定、金币收支、Elapsed |
| 战斗表现 | CombatFx Life、弹道、破壳、升级、攻击循环、地图局内粒子／动画、战斗音效播放进度 |

暂停菜单本身的UI交互、过渡与点击音使用独立时钟。菜单遮罩阻挡所有底层点击；DrawEgg、StartWave、Deploy、Recall、Sell、EvolvePool、EvolveTower、CastSkill均被模型拒绝。不能只停敌人位置而让CD、毒伤、池动画或金币继续。

点击继续或右上关闭，恢复原Stage和模拟推进；不得把暂停停留的真实时间作为一次巨大dt补算。已有合法宠物选择可恢复，暂停前尚未提交的拖放／技能瞄准取消，不恢复悬空输入。准备期恢复后仍需手动开波。

“重新开始”直接用同关、同实际队伍、同配置快照和同seed创建新模型，重置金币、HP、赠宠、Wave0、CD与计时；不额外增加确认。返回选关中止本局，不发通关奖励，不写本局胜利，清理暂停状态。Won/Lost不再打开战斗暂停菜单。

### U05：输入优先级与反馈规格

PC鼠标点击是首版完整路径。Esc依次取消当前星雨瞄准／未提交部署，若无临时操作则打开暂停；暂停菜单中Esc等同继续。右键只取消瞄准或当前宠物选择，不能出售。所有弹框、菜单与HUD先消费指针，再允许战场处理。

technical-artist与sound-designer的设计交接如下；这些是待制作事件，不是已生成资产。

| 事件 | 视觉要求 | 声音要求／并发优先级 |
|---|---|---|
| 抽蛋成功 | 扭蛋轻晃，蛋进入已确认的池槽 | 单次机械轻响；每次事务1次 |
| 孵化 | 蛋裂开后露出对应宠物，Uid位置排序后有轻提示 | 多只同帧孵化合成一组短铃声，避免10声叠加 |
| 进化 | 主体闪光／轮廓变大并显示新等级；战场主体位置不变 | 一次上升音；优先于普通攻击 |
| 7系攻击 | 羽弹／叶毒／泡泡／火团／岩块／光晕／暗翼弹，轮廓可区分 | 普通攻击最多6路，避免快速暗宠压过重要提示 |
| 基地失血 | HP跳变、出口短闪、伤害数值 | 警示优先于攻击；不得循环遮住菜单 |
| 星雨 | 明确范围预览和一次覆盖命中闪光 | 重要技能声；不能声画完成时再次伤害 |
| 错误提示 | 一条居中短提示，灰态保持可辨 | 轻拒绝音，跟随tips单例限频 |
| 暂停／恢复 | 灰遮罩和菜单过渡 | 战斗声暂停／恢复；UI声音可操作 |
| 胜负 | 可读结算和不同颜色＋文字，不靠颜色独立区分 | 一次结算短乐；状态只锁定一次 |

首版关闭强屏幕震动与全局命中停顿，避免与暂停合同混淆；原画、PNG、特效、音频均后续制作。级别1～5至少以数字、体型或附饰有可见差异，不能仅改伤害数字。最高级资源不足时明确采用阶段占位样式，不伪称已具备完整进化动画。

## 4. Formulas／时间与显示

游戏模拟有效dt：Running且未暂停／未终局时为输入dt，否则0。UI菜单计时取真实秒数；局内tips／折叠／孵化反馈在Paused时同样停止。所有真实输入由单次命令边界处理，不在IMGUI多轮绘制中重复提交。

tips剩余=max(0,2-累计可见UI秒数)；例显示0.5秒后暂停30秒，恢复还显示1.5秒。星雨显示CD=ceil(max(0,SkillRemaining))；显示0不赋予模型新的施放权限。动画0.18秒只影响表现，资源提交时刻不延迟0.18秒。

参考画面等比缩放因子=min(窗口宽/1920,窗口高/1080)；实际点击先逆变换到参考坐标，再映射战场归一化坐标；棋盘外的留边不能成为合法技能位置。

## 5. Edge Cases／边界情况

折叠池中的已选对象，隐藏面板和相关按钮；展开后只恢复仍存在的合法选择。排序后相同Uid仍被选中；进化成功按来源强制清选择。批量动画合并不能合并实际事务，9合3仍只有一次点击的快照。

暂停与点击战场同一帧时菜单优先，不透点。失去窗口焦点时EXT-D自动暂停非终局；回焦不自动继续，以免用户尚未准备；Preparing焦点恢复也不会自动开波。重试／返回后旧声音、效果或tooltip不能回调改动新局。

1280×720、1920×1080、2560×1440至少三种分辨率验收；文字、生命、金币、开波、暂停和14点可点击。窗口不是16:9时允许留边，不拉伸造成圆形范围失真。极小窗口可提示推荐分辨率，不能把被裁切按钮当作已适配。

## 7. Tuning Knobs／表现参数

| 参数 | EXT-D候选／范围 | 影响 |
|---|---|---|
| tips时长 | 2秒，来源固定 | 不能调成不断续期 |
| 折叠／菜单过渡 | 0.18秒；0.12..0.25 | 响应速度；不阻塞逻辑 |
| 遮罩alpha | 0.55；0.45..0.65 | 暂停信息层次 |
| 按钮最小尺寸 | 参考画面44×44像素 | 鼠标可点性 |
| 正文字号／关键数值 | 参考画面20／26像素以上 | 战斗可读性 |
| 普通攻击音并发 | 6；4..8 | 防止声部堆积；不影响攻击频率 |

这些参数属于表现层，不新增GameModel核心公开字段，不写入或覆盖本轮不允许编辑的文件。

## 8. Acceptance Criteria／验收标准

执行AC-U01～AC-U15。截图规定的信息与按钮相对位置、蛋无信息、空白取消、灰态解释、tips2秒不重复、独立收起、全冻结和继续／关闭／重试／返回全部必须验证。视觉测试单独留截图与操作录屏，不能用伤害单元检查替代。本文不主张逐条执行结果，实际覆盖见 `docs/verification.md`。
