# 美术方向与占位资源规格

状态：资源制作前的方向草案；尚未生成或导入美术资源。

## 1. 用户方向

参考《王国保卫战》的手绘卡通奇幻气质与战场可读性，制作原创宠物、敌人、地形和界面占位素材。使用 Unity 2D 表现，最终资源数量和内容随首版策划确定。

## 2. 视觉目标

- 斜俯视正交战场，暖色道路和绿色环境形成清晰的可通行／可部署区域差异。
- 宠物采用夸张比例、明确轮廓与简化内部细节，小尺寸下仍可区分角色职责。
- 阴影和轮廓线统一方向，减少贴图之间的漂浮感。
- 环境细节围绕玩法区域布置，路径、敌人、宠物与技能警示优先于装饰。
- 敌我同时通过轮廓、朝向、底座和颜色区分；不单独依赖红绿差别。
- UI 使用木质、石质或羊皮纸质感建立奇幻气氛，文字和数字保持高对比。

## 3. 资源制作清单骨架

| 类别 | 首批用途 | 规格建议 |
|---|---|---|
| 环境背景 | 首个关卡底图 | 1920×1080 或更高，同一正交视角，不含 UI、单位和烘焙路径 |
| 道路模块 | 对齐真实寻路路径 | 可拼接直道、转弯、端点；保持统一世界宽度 |
| 植被与装饰 | 地图外围丰富度 | 独立透明 PNG，可控制遮挡层级 |
| 宠物单位 | 体现战术定位 | 单个透明 PNG，建议 512×512；稳定脚底和统一占屏比例 |
| 敌人单位 | 区分不同威胁 | 同视角透明 PNG，体型与攻击表现一致 |
| 宠物蛋／孵化槽／扭蛋机 | 对应原案核心机制 | 先对齐交互规则，再制作 idle、可用、完成等状态 |
| 投射物与效果 | 命中、范围、控制提示 | 独立透明 PNG／粒子参数，避免遮挡目标 |
| UI 图标 | 血量、货币、回合、暂停、升级 | 简洁轮廓；文字由 Unity 绘制 |

## 4. 生成与导入约束

1. 使用 imagegen 生成实际位图资产；每张图记录用途、最终提示词及来源。
2. 单位与图标要求真实透明背景，检查 alpha 通道；不把棋盘格图案当作透明。
3. 背景不预烘焙单位、HUD、数字或必须交互的地块标记。
4. 宠物、敌人、地形分开生成，固定视角、照明和轮廓线标准。
5. 游戏最终引用的资产必须复制到项目的 Assets 下，不能仅引用生成工具的默认目录。
6. 资源名称使用稳定语义 ID，避免“最终版2”一类难以追踪的命名。
7. 先在实际 Unity 战场尺寸下检查轮廓和对比，再扩展资源数量。

## 5. 占位阶段验收

- 不放大观看也能分辨各宠物、敌人和主要交互入口。
- 真实移动路径与画面道路一致。
- 透明区域无底色、边缘无明显杂色。
- 攻击范围提示、危险提示和选择态均有形状或图标辅助。
- 资源可独立替换，不需要修改伤害、波次或宠物成长逻辑。
- 原文尚未确认的具体宠物、阵营、数量与技能图标不提前冻结为设计要求。
