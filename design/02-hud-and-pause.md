# 局内 HUD 与暂停系统规格草案

版本：0.1 草案。  
来源：SRC-HUD-001～005、SRC-PAUSE-001～005；新增补全标为 EXT。  
状态：截图可确认部分已整理；仍需对齐原文信息面板、输入及其他系统细节。

## 1. Overview／概述

局内 HUD 以血量、金币、回合进度为常驻核心信息，提供暂停、扭蛋和孵化池入口。暂停保持地图可见，隐藏局内 HUD，以半透明灰色遮罩和菜单覆盖战场。

## 2. Player Fantasy／玩家体验

玩家能快速判断防线情况、可用资源和当前进度；暂停提供稳定的思考与离开入口。恢复后世界状态应与暂停瞬间一致，不补算暂停期间的战斗。

## 3. Detailed Rules／详细规则

### 主 HUD

| 区域 | 截图依据 | 补全草案 |
|---|---|---|
| 血量和金币 | 左上角；同时显示图标和数值 | EXT：数字固定宽度，资源变化短促反馈，不用颜色独立表达 |
| 当前／总回合 | 上方中央附近 | EXT：从关卡数据读取总回合，禁止写死 |
| 暂停 | 右上角 | EXT：按钮具备 hover、按下、禁用状态；Esc 为 PC 快捷键 |
| 扭蛋机 | 右侧 | EXT：费用、可操作条件及失败提示待抽取章节对齐 |
| 孵化池 | 下部靠右 | EXT：容量、状态与可用操作待孵化章节对齐 |
| 宠物信息面板 | 截图下方仅露出标题 | 尚未确定具体字段，不自行标为原文要求 |

EXT：首版基准画面 1920×1080，使用等比 UI 缩放；同时验收 1280×720、1920×1080 和 2560×1440。核心信息保持在画面内部安全边距，布局不依赖截图的绝对像素坐标。

### 暂停进入

1. 从战斗界面点击暂停入口。
2. 将局内模拟切换为 Paused，冻结敌人移动、防御塔攻击、技能释放、技能冷却、BUFF/DEBUFF。
3. 隐藏常规战斗 UI；地图保持显示，显示灰色半透明遮罩。
4. 菜单显示：回到选关界面、重新开始、继续、右上角关闭。

EXT：处于拖放预览时进入暂停，取消尚未提交的拖放，不扣资源；已经原子提交的操作保留。暂停菜单拦截全部指针事件，不能透点到底层战场。

### 暂停期间

原文明确的冻结项全部停止推进。EXT：弹道、波次间隔、延迟伤害以及其他属于本局的计时也使用同一局内时钟；孵化和能量是否有独立时钟需与正文对齐。菜单交互和菜单过渡动画使用不受暂停影响的 UI 时钟。

EXT：重复点击暂停不形成多层暂停栈。暂停期间拒绝战斗、部署、升级和抽取指令；不因反复打开菜单重新初始化技能或状态效果。

### 继续与关闭

原文：点击继续或右上角关闭，恢复局内行为和 UI。

EXT：恢复此前合法运行倍率；若没有倍率系统，则恢复 1×。不把暂停停留时间当作一大段 deltaTime 注入模拟。Esc 在暂停菜单中等同继续。

### 重新开始

原文：重置当前关卡初始状态。

EXT：销毁旧关卡运行态，重新加载当前关卡定义，重置局内实体、波次、资源、计时与待执行事件。随机种子是否复用、是否扣除局外进入资源，待原文对齐。初始化结束进入首个正常可操作状态。

### 返回选关

原文：提供返回选关界面入口。

EXT：中止局内模拟、移除临时选择和拖放状态，恢复全局时间设置并加载选关界面。退出是否保留中途进度或发放奖励，必须由结算／存档规则决定，不能借由返回按钮隐式结算。

## 4. Formulas／时间与显示

```text
局内时间增量 = 真实帧间隔 × 有效模拟倍率
有效模拟倍率 = Paused 或 Ended 时为 0，否则为当前运行倍率
UI 动画时间增量 = 真实帧间隔
回合显示 = 当前回合编号 / 关卡总回合数
```

补全约束：资源显示不参与扣款计算；UI 读取唯一游戏状态。浮点计时允许实现误差，但暂停前后不能推进任何正时长。

## 5. Edge Cases／边界情况

- 暂停与敌人到达终点同帧：按统一指令处理顺序结算一次，不能重复扣血。
- 结算后点击暂停：不再切回战斗暂停态。
- 鼠标在暂停遮罩上点击地图：不能选择、部署或出售宠物。
- 暂停 30 秒后继续：冷却、敌人进度、状态剩余时长与暂停前一致。
- 连续暂停／继续：不叠加或丢失恢复回调。
- 暂停后重试或返回：不把时间倍率 0 泄漏给新关卡或选关界面。
- UI 分辨率改变：按钮仍可见，核心数值不被裁切。
- 宠物信息面板打开时暂停：隐藏其战斗展示；恢复策略与原文面板交互再对齐。

## 6. Dependencies／依赖

局内状态机、模拟时钟、波次、战斗、技能、状态效果、经济、部署、场景流转、结算。HUD 不拥有货币、生命或宠物实例，只显示领域状态和提交指令。

## 7. Tuning Knobs／可调项

| 参数 | 草案范围／值 | 影响 |
|---|---|---|
| HUD 安全边距 | 画面短边的 3%～5% | 边缘可读性 |
| 暂停遮罩透明度 | 0.45～0.65，待美术验证 | 战场与菜单分离 |
| PC 主操作目标 | 基准分辨率下至少 44×44 像素 | 点击可靠性 |
| 关键数字字号 | 基准分辨率下至少 24 像素 | 战斗读取 |
| 菜单过渡时间 | 0.12～0.20 秒 | 反馈速度；不延迟模拟暂停 |

以上为 EXT 初始候选，不是原图的测量值。

## 8. Acceptance Criteria／验收标准

| 用例 ID | 操作 | 预期 |
|---|---|---|
| PAUSE-01 | 敌人移动和攻击中暂停 30 秒 | 敌人位置、HP、攻击计时均不变化 |
| PAUSE-02 | 技能 CD 和持续效果计时中暂停 | CD、效果剩余时长不推进，无周期伤害 |
| PAUSE-03 | 分别点击继续与关闭按钮 | 战斗和 HUD 均恢复，时长不跳变 |
| PAUSE-04 | 暂停后重新开始 | 当前关卡恢复初始运行态，无旧实体或延迟事件 |
| PAUSE-05 | 暂停后返回选关，再进入关卡 | 新关卡正常运行，无暂停残留 |
| PAUSE-06 | 在菜单和遮罩覆盖区域点击 | 不触发任何底层战斗操作 |
| PAUSE-07 | 连续切换暂停／继续 20 次 | 状态和倍率保持正确 |
| HUD-01 | 三种目标分辨率查看 HUD | 生命、金币、回合、暂停均清晰可见 |
| HUD-02 | 资源不足或孵化池已满 | 依对应系统给出原因；不重复扣款或丢失宠物 |
